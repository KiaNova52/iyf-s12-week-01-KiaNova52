# Kelvin Kiarie — Personal Portfolio

## About This Project
This is my first personal portfolio website, created as part of the IYF Season 12 Web Foundations program.

The website introduces me, highlights my interests, and provides a way to contact me.

## Live Demo
[View My Portfolio](https://kianova52.github.io/iyf-s12-week-01-KiaNova52/)

## Technologies Used
- HTML5
- Git and GitHub
- GitHub Pages
- Visual Studio Code

## Features
- Personal introduction
- Profile placeholder image with alternative text
- Hobbies and interests list
- Link to MDN Web Docs
- Email contact link

## How to Run Locally
1. Clone this repository.
2. Open the project folder in Visual Studio Code.
3. Open `index.html` with the Live Server extension.

## What I Learned
- Basic HTML document structure
- HTML headings, paragraphs, lists, images, and links
- Using Git to track and submit changes
- Publishing a website using GitHub Pages
